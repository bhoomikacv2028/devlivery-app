# QuickShop App

A MERN stack application featuring a home page, user authentication, and a shopping cart.

## 🌟 Key Features
- **User Authentication:** Login and Sign-up functionality.
- **Home Page:** Displays available products.
- **Shopping Cart:** Add and manage items.

## 🛠 Tech Stack
- **M**ongoDB
- **E**xpress.js
- **R**eact.js
- **N**ode.js
- **Tailwind CSS** (Styling)
